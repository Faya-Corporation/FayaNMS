# FayaNMS brand assets

Canonical brand masters. Treat these files as governed artifacts:

| Asset | Usage | Notes |
|---|---|---|
| `fayanms-mark.svg` | Primary product mark (app surfaces, currentColor) | Protected-network motif: nodes inside an operations ring |
| `fayanms-mark-brand.svg` | Static brand-blue mark for **`<img>` contexts** (README, docs, email) | External images cannot inherit `currentColor` — this master paints fixed brand blue (re-audit B1-013) |
| `fayanms-mark-micro.svg` | Favicon micro-mark, 16–20 px | Same ring, **solid** nodes, solid simplified hub, **no connectors** (re-audit B1-014); `src/app/icon.svg` + ICO tiles derive from it |
| `fayanms-mark-mono.svg` | Print / export / low-color contexts | Pure black |
| `fayanms-mark-white.svg` | Dark or photographic backgrounds | Pure white |
| `fayanms-wordmark.svg` | Standalone wordmark master | Regenerable; in-app wordmark is the `FayaNMSWordmark` text component |
| `fayanms-lockup-horizontal.svg` | External horizontal lockup | Mark + wordmark + descriptor |
| `fayanms-lockup-horizontal-white.svg` | Horizontal lockup on dark backgrounds | |
| `fayanms-lockup-stacked.svg` | Square / vertical placements | |
| `fayanms-noc-mark.svg` | NOC wallboard / operations-center context only | Sub-brand, not a second logo |
| `fayanms-network-shield.svg` | Security / protected-configuration context | Secondary symbol — never a logo substitute |

Rules: never stretch, skew, rotate, shadow, animate, or recolor with status
colors. Clear space ≈ one node diameter. Minimums: 16 px favicon (micro-mark),
20 px nav mark, 32 px header lockup, 40 px sign-in, 64 px+ docs/report covers.

Generation: the mark-family masters (`fayanms-mark`, `-brand`, `-micro`, `-mono`,
`-white`) are **geometry-derived** — regenerated by `bun run brand:raster` from
`src/lib/brand/mark-geometry.ts`; do **not** hand-edit them (validators re-derive
them byte-for-byte and fail on drift). The wordmark/lockup files remain typographic
templates (`Inter, 'DejaVu Sans', sans-serif`): they may render with a fallback
sans-serif when Inter is unavailable and are not pixel-identical across systems.

See `docs/brand/BRAND-GUIDELINES.md` and `docs/brand/ASSET-MANIFEST.md`.
