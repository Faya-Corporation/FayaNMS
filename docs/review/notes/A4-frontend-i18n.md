# A4 — Frontend / i18n / Accessibility / Client-side Security Audit

Scope: `src/app/**`, `src/components/**` (spot-checks, heaviest surfaces), `src/hooks/api/**`, `src/stores/**`, `src/i18n/**` + `messages/{en,ar}.json`, forms, empty/loading/error states, destructive-action confirmations, a11y. READ-ONLY audit; no code changed.

Architecture context: single user-visible route `/` (ADR-02) → `AppShell` → client-side `ViewRouter` over ~45 views. i18n via next-intl (`LocaleProvider`, hydration-safe, `dir` flip post-mount). State: zustand (+persist) + TanStack Query; all fetches go through `src/lib/api-client.ts` (`ApiError`, envelope unwrap).

## i18n parity: `messages/en.json` vs `messages/ar.json`

Method: bun script flattening both JSON files to dotted key sets and diffing (`/tmp/parity.mjs`, `/tmp/same.mjs`).

- **en keys: 2850 · ar keys: 2850**
- **en-only keys: 0**
- **ar-only keys: 0**
- Key parity is exact — full parity, nothing to list (limit 20 n/a).
- Depth check: 21 keys have byte-identical en==ar values; all benign (placeholders, technical tokens, proper nouns), e.g. `capacity.model.backtestRange` = `"{from} – {to}"`, `collectors.distribution.role.netflow` = `"NetFlow"`, `language.en` = `"English"`, `reports.scheduled.dialog.recipientsPlaceholder` = `"noc@faya.local, admin@faya.local"`, `credentials.authMethod.snmpv3` = `"SNMPv3"`. No untranslated prose detected.
- The real i18n debt is **hardcoded strings in components/hooks** (A4-02..A4-06, A4-08), not dictionary gaps.

## Positives verified (no action)

- No unescaped device-data rendering: only `dangerouslySetInnerHTML` is chart style config (A4-11); assistant-tab's markdown is a tiny React-node renderer (no raw HTML); config/diff render as text in `whitespace-pre-wrap`/code elements.
- No `target="_blank"` without rel, no `window.confirm`; destructive actions (backup policies, baselines, maintenance, alert rules, API-client rotate, guarded restore) use `AlertDialog`/`HighRiskActionDialog` (typed confirm phrase, never closable mid-flight).
- Stores persist UI-only data (`fayanms-prefs`, `fayanms-device-views`, `fayanms-list-views`, navigation) — no secrets/PII in localStorage; credentials carry vault `secretRef` only (F-12 invariant holds client-side).
- Icon-only buttons audited (app-header ×9, app-sidebar, reports, job-center, stream item) all have localized `aria-label`; directional icons use `rtl:-scale-x-100`; badges use logical `-end-` offsets; skip-link, `aria-busy`, `aria-live="polite"` (10 files), focus-managed guided tour (focus move, Tab trap, Escape) all present.
- All debounced timers/interval effects clean up (command palette, views, noc-view wall-clock uses `useSyncExternalStore` with subscriber-count cleanup); TanStack Query handles unmount races; query keys centralized and prefix-invalidated correctly (`queryKeys`).
- QueryProvider defaults sane (`staleTime 15s`, `retry 1`, no window-focus storms).
