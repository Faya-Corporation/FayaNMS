# A2 — Protocol engines, collectors & Bun worker (device-facing trust boundary)

Branch GLM/full-audit-and-fix · read-only audit · Task 5-b. Scope: `mini-services/worker/**`, `src/lib/protocol|collectors|flows|net|dns|ssh|vendors/**`, ingest paths (UDP syslog/SNMP-trap/NetFlow, protocol event queue/drain), worker↔app auth, credential/vault handling, live SSH/WebAPI transports, controlled-change command building, poller scale.

**Trust model observed (what is trusted):** the app trusts the worker's service JWT (scopes `jobs`/`telemetry`/`simulate`); the worker trusts app-supplied payloads only after typed re-validation (target policy, host-key pin, credential-ref grammar); devices are NEVER trusted (bounded output, allowlisted commands, fail-closed pins). Secrets cross boundaries as `secretRef` only; the worker resolves them worker-side. This model is largely enforced and tested; findings below are the residual gaps.

**Positive verifications (no finding):** SAFE-001 host-key pinning is fail-closed everywhere (unpinned live = refused; mismatch dies pre-auth; first-contact capture is credential-free and aborts during KEX — ssh-transport.ts:231-309); controlled changes are plan-tokenized (no command text crosses app→worker; regex-gated anchor/slug; no quotes/newlines — live-change.ts:44-48, change-commands.ts); resolve-then-dial TOCTOU closed (worker dials the validated address — target-policy.ts:301-406); SNMPv3 traps verified (HMAC w/ timingSafeEqual + authPriv decrypt) with boots/time monotonic replay rejection + conditional-update race guard (snmpv3-policy.ts:68-79, accept/route.ts:46-50); NetFlow v5 decoder + zod schema strictly length/value-bounded (30 records, 16 KiB); claim enrichment carries `secretRef` only; vault never logs secret values; runner/scheduler/claim loops are self-scheduling with exponential backoff and bounded queues; change steps serialize per device via DB write locks.
