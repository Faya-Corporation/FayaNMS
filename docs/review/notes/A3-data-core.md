## Clean bill of health (checked, no finding)

- **Schema constraints**: explicit `onDelete` everywhere per policy (Cascade owned / SetNull optional / Restrict important history: Vendor, ChangeRequest.requester); composite unique keys for join tables (`ChangeDevice`, `IncidentDevice`, `ChangeApproval [changeId,level]`, `CmdbRelation`), 101 `@@index` declarations covering the hot filters I traced; `@@unique([prevHash])` DB-level chain fork protection; SAFE-003/005 lease/lock-as-PK patterns are sound.
- **Migrations**: all 13 are additive (ADD COLUMN / CREATE TABLE / CREATE INDEX); `migration_lock.toml` = postgresql; no destructive/rewording steps spotted; reversible via documented down path only (no down migrations — normal for Prisma).
- **Secret crypto (src/lib/config/crypto.ts)**: AES-256-GCM envelope with per-row DEK, AAD row binding, timing-safe digest verify, loud failure on missing KEK, `enc1:` versioned small-secret envelope — no findings. Startup security policy (startup/security-policy.ts) fail-closed, known-bad blocklist, postgres-only URL check — no findings.
- **Time zones / epochs**: consistent `Date`/epoch-ms usage across evaluate, tick windowing, flow `receivedAt` windows, capacity (UTC `getUTCDay`); no epoch-seconds/ms mixups found. Cron matcher implements Vixie dom/dow union correctly (tick/route.ts:133-153); evaluates in server-local TZ (documented cron semantics, containers run UTC — noted, not a finding).
- **Threshold comparison**: `compare()` (evaluate.ts:158-173) matches operators incl. epsilon-EQ; avg-over-window + 2-window recovery is a reasonable anti-flap design (only AVAILABILITY recovers immediately, by design).
- **Queue/job claim atomicity**: protocol drain (drain/route.ts:101-134) and job claim (worker/claim/route.ts:68-95) use conditional `updateMany` CAS with lease/lock timeouts — correct under concurrent claimants; FlowRecord persist is idempotent per queue row (`skipDuplicates` + `[queueId, recordIndex]`).
- **External calls**: webhook delivery has a hard 5 s AbortController timeout + SSRF egress gate + redirect refusal (integrations/delivery.ts); worker `nextPost` calls are timeout-bounded.
- **Reports**: row-capped (MAX_ROWS 500), CSV RFC-4180 escaping correct; math mirrors the APIs (but inherits the A3-02 empty-rollup problem).
- **CMDB impact BFS**: cycle-safe visited set, depth-capped, deterministic ordering (cmdb/impact.ts) — no findings.
